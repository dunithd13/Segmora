# Notebooks

This folder contains Google Colab / Jupyter notebooks for each phase of the Segmora project.

- `01_eda.ipynb` — Data understanding and exploratory data analysis
- `02_preprocessing_feature_engineering.ipynb` — Cleaning, RFM, and behavioural features
- `03_clustering_models.ipynb` — K-Means, Hierarchical, DBSCAN, and GMM experiments
- `04_evaluation_recommendations.ipynb` — Evaluation, stability analysis, PCA, and business recommendations
- `segmora_end_to_end_final.ipynb` — Final integrated notebook for submission
